Aidora es una plataforma web y móvil que conecta a personas que desean donar medicamentos especializados no utilizados con pacientes de enfermedades crónicas que enfrentan desabasto en instituciones públicas en México. Incorporamos validaciones digitales para garantizar que las donaciones sean seguras y legales.

La plataforma prioriza la verificación del Registro Sanitario (COFEPRIS), la fecha de caducidad y la clasificación legal del medicamento para asegurar que solo se canalicen fármacos no controlados y en condiciones adecuadas.

Tecnologías y alcance

Aidora se apoya en una arquitectura de sistemas distribuidos que conecta la aplicación web y móvil mediante una base de datos compartida para la persistencia de datos. Nuestro equipo domina Java (nivel básico-intermedio), JavaScript básico, HTML, CSS y SQL.
